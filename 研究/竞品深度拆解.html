01城市财经（头部 · 全国覆盖 · 商业变现最成熟）

定位：全国城市经济 / 产业 / 楼市解读。前财经记者团队，全网 120 万+ 粉，矩阵化运作。
核心用户全国城市中产、潜在购房者、区域经济爱好者；公众号用户偏中老年、普通人。
内容生产线 选题：覆盖广 + 直击痛点 + 社交传播原动力；三路找题——追热点（微博/看一看/热榜）、拆同行（头部 1万+ 纳入选题库）、挖长期刚需。
标题：数字型点击率高 36%；五公式——数字+痛点型 / 反差对比型（"本以为…没想到"）/ 悬念揭秘型 / 痛点提问型 / 民生共情型。
结构：痛点前置 → 1/2/3 分点短段 → 生活化案例（买菜/带娃/养老）→ 共情句 → 埋互动点 → 引导评论。
算法：2024 底改版后算法推荐取代订阅，读完率（停留时长）是生死线；哪怕 0 粉，硬文也能推到 10万+。
爆款逻辑平台偏爱冲突 / 干货 / 情绪 / 民生 / 反差；一篇硬内容 > 粉丝量。标题决定 80% 打开率，同一文换标题阅读量可差 12 倍。
数据质量二手整合为主（统计公报、房天下月度、地方海关）；口径偶有混（户籍/常住不分）。强在速度的广度，弱在原创深度。
变现路径流量主（垂类点击价值高） + 软文发稿（城市宣传稿约 1.9 万/篇） + 矩阵互导。

✅ 可借鉴（给城经笔记）

  • 标题公式化：每篇套"数字+痛点+解决方案"，如《3 张图看懂 XX 房价见底没》。
  • 栏目化 + 热点反应速度：固定系列（城市体检/旅居决策），热点 30 分钟内出角度。
  • 开头黄金 5 秒：提问式/故事式留人，提升读完率（直接决定推荐权重）。

⚠️ 不要抄

  • 商业软文多 → 伤独立性（你的护城河正是"不碰楼盘软文"）。
  • 全国覆盖稀释单城深度；标题党焦虑式表达与你的"数据求真"人设冲突。

02三土城市笔记（长三角深度 · 鲜明观点 · 社群黏性）

定位：长三角区域 + 房产投资深度解读。雪球 2018 起家，现 35 万粉；主理人"土哥涅夫"。与城经笔记选题重叠度最高。
核心用户长三角迁居 / 置业决策者、房产投资者；群友"天南海北"，常问"我该去哪座城"。
内容生产线 选题："从老百姓关心的话题出发"，平衡"想表达"与"受众关注"；早期聚焦杭州，后扩至宁波/南京/无锡等。
风格：硬核财经分析 + 反共识泼冷水。代表作《我现在倒是有些担心杭州了》30万+（全网吹捧时逆向提醒）。
数据：贴原始表格（财政/人口/房价），读者可核对，建立"数据硬"信任。
爆款逻辑反共识 + 敢说真话。首篇 40万+ 为杭州区划调整系统梳理；"担心杭州"逆向观点收割 30万+。情绪来自"别人捧、他泼冷"。
数据质量在原号中偏硬核（一手数据表格 + 长周期跟踪）；但房产投资导向强，立场鲜明到偶有"地域争议"。
社群变现十几个读者群（扫码满员→个人微信 tgnf1987 拉）+ 免费知识星球 + 线下见面会；早期即建群，群友反哺选题。"和读者对话"是高黏性来源。

✅ 可借鉴（给城经笔记）

  • 早期就建读者群：哪怕只有几十人，群聊反哺选题（你目前社群=空白，最该补）。
  • 观点鲜明、敢泼冷水：如你那张"宁波 2025 常住仅 22.6%、别被户籍 31.4% 吓到"就是反共识求真，正合此道。
  • 读者互动出题：文末留"你想看哪座城？"收集选题，形成共创感。

⚠️ 不要抄

  • 房产投资导向游走在合规边缘；极端观点易引发骂战、限流。
  • 只覆盖长三角，你应走"全国旅居+居住决策"更宽赛道，不与他正面重叠。

03国民经略（数据政策派 · 系列沉淀成书）

定位：城市观察 / 楼市逻辑 / 政策解读。主理人凯风（清华背景），文章总阅读 3 亿+，出书《中国城市大趋势》。
核心用户宏观城市格局关注者、政策研究者、长线"选城市"决策者。
内容生产线 框架：宏大叙事（一线城市 / 强省会 / 都市圈 / 国家战略），政策 + 数据双驱动。
风格：冷静、权威、学术引用；不煽动焦虑，重趋势判断。
沉淀：系列文章 → 系统化 → 出书（《中国城市大趋势》清华出版，定价 79，已重印 11 次）。
爆款逻辑政策解读 + 趋势预判的长尾复利；单篇不靠情绪，靠"框架可信"累积权威背书。
数据质量三家里最严谨之一（学术/政策出处清晰）；弱在"不落地"——读者看完知道格局，不知自己咋办。
变现路径出书（知识付费天花板） + 流量主。把免费流量沉淀为付费实体/电子产品，是最高效的"信任变现"。

✅ 可借鉴（给城经笔记）

  • 系列沉淀为付费产品：你的"城市体检系列"10–20 篇可汇编成《城市居住决策手册》电子书/知识星球年费。
  • 权威背书感：每篇标注数据来源 + "本人实地核实"，强化"数据求真"差异化。

⚠️ 不要抄

  • 纯宏观不落地，与你的"帮普通人做居住决策"落点相悖——你要在宏观后补"所以你该咋办"。
  • 更新慢、单人产出，初期难复制；你的 SVG 可视化是它缺的"轻量可读"优势。
