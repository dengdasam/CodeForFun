Tauri 2 与 .NET 桌面架构对比

以「皮卡鱼象棋」这个 21.5 MB 的真实 Tauri 2 应用为切入点，用同一台 Win11 机器上的实测基准数据，量化 Tauri 与 .NET（WPF / Avalonia）在体积、内存、启动、分发上的真实差异。

2026-11 实测数据 Tauri 2.11.6 .NET 10 / Avalonia 12.1 Windows 11 x64

一句话结论：Tauri 相对 .NET 的核心优势是分发体积小一个数量级（1 MB vs 56 MB），但它的内存表现反而更差（142 MB vs 74 MB）——省下的是磁盘，不是内存。这个优势高度集中在「Windows 单平台 + 界面为常规表单/列表/图表」的场景。

值得借鉴的设计：web-bundles/<seq>/ 配合 manifest.json 的 min_contract / min_build 版本下限，意味着改界面不必重发 exe，只推新的 bundle 序号即可。这套「引擎独立进程 + 文本协议 + 前端热更」的架构，换成 .NET 同样能实现。

03Tauri 相对 .NET 的六条真实优势

优势具体表现适用判断
① 分发体积碾压 1 – 15 MB，对比 WPF 自包含 56 MB、Avalonia AOT 34 MB 要分发给不懂技术的用户、走群分享/网盘时，下载成本近乎为零
② 不要求装运行时 只用 Win10/11 自带的 WebView2，无需 .NET Runtime 关键约束：.NET 要么让用户装 60 MB 运行时，要么自己背 56 MB
③ 前端可热更新 换 web-bundles/<seq>/ 序号即更新界面，不重发 exe 改 UI 不必重新安装、不必通知用户，下次启动自动生效
④ UI 开发效率 Vue/React + CSS，改样式即时生效，无需学 XAML 绑定语法 已有 Web 前端能力可直接复用
⑤ 前后端天然分离 Rust 管引擎/文件/网络，前端只管界面，通过 IPC 通信 换引擎、换 UI 互不影响（皮卡鱼正是此结构）
⑥ 内存安全 + 无 GC 停顿 Rust 无 GC，长时间跑引擎搜索不会出现内存峰值抖动 批处理、长任务、实时计算场景更稳定

04.NET 明显更强的地方

.NET（WPF / Avalonia）胜出

  • 内存占用：74 MB vs 142 MB，几乎省一半
  • 启动速度：框架依赖版近乎瞬开，无 WebView 进程拉起
  • 原生控件：DPI 缩放、输入法、无障碍、右键菜单天然正确
  • 大数据表格：DataGrid 虚拟化成熟，几万行不卡；Web 侧是老大难
  • 调试体验：Visual Studio 断点、Live Visual Tree、性能剖析
  • 无运行时风险：自包含版到哪都能跑

Tauri 的明显短板

  • WebView2 强依赖：Win7 及部分精简版 Win10 没有，企业环境常被策略禁用
  • 三平台 WebView 引擎不一致（Windows/WebKit/WKWebView），需各测一遍
  • 媒体栈弱：实时音视频不如 Electron / 原生
  • 调试链路长：Rust 与 JS 两个世界，跨语言排查成本高
  • 后端要写 Rust：学习曲线 2 – 4 周起步
  • 首屏闪白、输入法、右键菜单需自己补

05决策表：什么场景选什么

场景选择理由
小工具（< 30 MB）、Windows 单平台、常规表单/列表/图表界面、要分发给非技术用户 Tauri 体积优势最大化，且现有 HTML/前端代码几乎不用改
需要与现有 C# 代码/库深度集成、界面大量原生控件、Windows 专属且确定有运行时 WPF / Avalonia 避免用不熟的语言重写，且内存与启动都更优
内存紧张的老机器（4 – 8 GB）、工业终端、7×24 常驻 WPF 或 Qt 内存与启动稳定性优先，放弃 Web 技术栈
必须支持 macOS + Linux 慎选 Tauri 三家 WebView 表现不一致，需分别验证；Electron 更稳
实时音视频、专业媒体工具 不选 Tauri 媒体栈弱，Electron / 原生 / Flutter 更合适
想保留 Web 前端但不愿碰 Rust .NET + WebView2 控件 Microsoft.Web.WebView2 可做到 80% 同样效果，启动更快

06可迁移的架构经验

皮卡鱼这套设计值得借鉴的地方，与「选 Tauri 还是 .NET」无关——换任何技术栈都能照搬。

  • 引擎独立进程 + 文本协议：Pikafish.exe 通过 UCI（uciok / bestmove / position fen）通信，不静态链接。好处是引擎可替换、崩溃不拖垮 UI。.NET 里用 Process + stdin/stdout 完全等价。
  • 配置双文件轮换：desktop-config.a 与 .b 均为 2192 字节并带 "generation": 3 计数，先写备用文件、校验通过再切换，防断电写坏。
  • 前端资源版本化外置：manifest.json 里 seq 递增 + 每个文件带 SHA-256，配合 min_contract 下限防止新前端配旧后端。
  • 数据目录与安装目录分离：棋谱库指向 D:\PikafishLibrary（library-storage.json），备份时不能只备份 AppData。
  • 静态链接 CRT：导入表仅 30 个系统 DLL、620 字节，全部走 api-ms-win-crt-*，所以不需要预装 VC++ 运行库，绿色便携。
