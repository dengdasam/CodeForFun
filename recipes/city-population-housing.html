四城人口结构 vs 房价见底验证

南宁 · 广州 · 杭州 · 宁波 — 用「老龄化→房价见底」模型做历史 / 当前 / 预测三段式验证

人口结构说明：人口结构 = 一个城市人口按年龄切分的构成。对房价起决定作用的是三点—— ① 购房主力（25–44 岁）是否充足；② 老龄人口（60+）占比；③ 人口靠“生”（自然增长）还是靠“搬”（机械 / 净流入）增长。 四城当前结构画像：
· 南宁：最年轻友好——常住人口正增长、省域核心持续吸人，60+ 仅 16%，购房主力在补。
· 广州：常住老龄化最轻（户籍 60+ 20.3% 但常住更轻），且出生率 9.97‰（全国前列）+ 年净流入 12 万，结构“又生又吸”。
· 杭州：60+ 已达 21.3%（比广州老），净流入仍在（+7.6 万）但增量逐年放缓（2021 +26.8 万 → 2025 +7.6 万），结构“吸力减弱”。
· 宁波：户籍 60+ 高达 31.4%、自然增长 −1.5‰（生死倒挂），增长 100% 靠外来打工人口——本地结构已“老且不生”，靠低购买力外来者吊命。

读图要点：宁波户籍线在 2025 已越过 30% 红线（实线段就已破线），2030 后冲向 36%+，是四城唯一“本地窗口已关”的样本；南宁 / 广州 2040 前都贴近或低于阈值、靠流入兜底；杭州约 2030 年代初逼近阈值。

房价变动说明： 峰值时点：四城均在 2021–2023 泡沫期见顶（南宁 2021–22、广州 2021、杭州 2023-04、宁波 2022-02），随后普遍回落。

结构性解读：广州 / 南宁下跌主因是周期性回调（泡沫破裂 + 库存），人口结构未恶化，故跌得浅、率先企稳；宁波是结构性 + 周期性双杀——本地老龄化 + 无年轻接盘 + 挂牌天量，故跌最深最久；杭州超跌更多源于天量供地 / 产品迭代冲击而非纯人口老化，与模型“老龄化是底层拖累、非唯一原因”一致。

房价预测说明（修正版 · 低位横盘而非回升）： 为什么之前版本假设“回升”是错的？ 人口结构模型只决定“见底时点与深度”，并不导出“见底后上涨”。2021–2026 四城普跌，主因是房地产去杠杆 + 泡沫破裂 + 库存（周期性回调），与人口结构无关——模型只解释“谁跌得浅、谁跌得久”，不预测反弹。
修正后的逻辑：① 广 / 南 / 杭窗口未关、年轻流入仍在，故约 2027–29 止跌筑底；② 但中国总人口与 25–44 购房主力长期收缩，全国买家池持续变小，城市级流入只能让“需求不再恶化”，缺少重新上涨的引擎（无加杠杆空间、收入增速放缓）；③ 因此合理路径是低位横盘 + 仅随通胀的轻微名义回升，实际（剔除通胀）价格长期停滞甚至继续阴跌，到 2040 仍显著低于 2021–23 峰值（见“较峰值”列：−7% ~ −18%，宁波 −45%）。
宁波最弱：本地窗口 2025 已关、纯靠低购买力打工流入，结构性底部最晚（2029–32）、回血最慢，2040 指数仅 96（仍低于当前），呈“深 L”而非“V”。
关键验证：宁波「房价结构性底部（2029–32）」比其「红利窗口关闭（2025）」滞后约 5–7 年、比「劳动年龄见顶（2013）」滞后约 17–19 年，落在模型「滞后 15–25 年」区间内，四城验证闭环完成。

四、套模型验证（是否符合预测？）

✓
宁波 = 模型最纯粹的兑现。 户籍 60+ 31.4% 越过 30% 阈值、自然增长 −1.5‰、靠安徽/河南/贵州打工人口机械增长——本地无人接盘、外来者购买力弱 → 跌幅最深 −43%，完全符合「无年轻流入对冲 → 崩」。
✓
广州 / 南宁 = 反向验证（流入对冲 → 不崩）。 广州出生率 9.97‰ + 机械 +11 万、南宁连续正增长——人口红利窗口开着，25–44 购房主力持续补充 → 跌幅最浅（−15%）、率先企稳。
✓
杭州 = 中间态，窗口收窄但未关。 老龄化快于广州（60+ 21.3%）、增量放缓，但仍有净流入 + AI 产业强基本面 → 二手超跌 −22% 更多源于供应过剩，与模型「老龄化是底层拖累、非唯一原因」一致。
✓
时间轴吻合「滞后 15–25 年」。 中国劳动年龄人口 2013 年见顶，本轮下跌以 2021 泡沫破裂 + 库存为主因、老龄化为底层拖累，结构性底部落在 2030s–2040s，逻辑自洽。
✓
城乡分化成立。 宁波各县市户籍老龄化更重（余姚/奉化/慈溪 60+ 均 35%+），结构性风险最高；核心城区靠聚集效应相对抗跌——印证「崩的是人口流出地」。

推导链：人口结构 → 红利窗口关闭（宁波 2025 已关 / 杭州约 2030s / 广南 2040 前不关）→ 25–44 购房主力见底（再滞后）→ 房价结构性底部（再 +15–25 年，落在 2030s–2040s）。即当前下跌以周期为王，老龄化是底层拖累；越靠后、人口越流出的城市，结构性底部越深越久。

结论：模型在四城得到完整验证

城市分化的唯一主轴，就是年轻人口净流入能否盖住本地老龄化——这恰恰是我们模型的核心命题。

· 南宁、广州靠「年轻人口持续流入」把老龄化见底推到遥不可及的将来（跌最浅 −15%、最早企稳）。

· 宁波因「户籍重度老龄化 + 自然负增长 + 低购买力流入」成为四城最脆弱样本（跌最深 −43%、见底最晚）。

· 杭州居中，窗口收窄但未关，超跌主因是供应过剩而非纯人口老化。
